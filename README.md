# Космические Рейнджеры: Возрождение

![Оттепель — концептуальная обложка проекта](assets/concepts/ottepel-project-cover-v1.png)

*Оригинальный концепт для досье проекта; не готовый игровой ресурс.*

Проект развития Space Rangers HD: A War Apart: нативный Linux и Steam Deck, сохранение художественного стиля и юмора, живая экономика и взаимосвязанные истории галактики.

## Текущий этап

Согласована основа мира: экономика, единый суточный календарь, постоянные личности и история кораблей. Первый игровой срез — промышленная планета «Оттепель» и кризис её снабжения.

Реализация игровых изменений ещё не начата. Подготовлена [энциклопедия исходной игры](docs/encyclopedia/README.md): каталоги контента, первичные сюжетные источники, правила симуляции и сравнение наших 38 направлений с существующими механиками. [Издание энциклопедии в Notion](https://app.notion.com/p/40c99aa2eb7b811eae5ecbdb4f22fbae) связано с проектной документацией, идеями, планами и журналом [«Возрождения»](https://app.notion.com/p/40c99aa2eb7b815d9959f1b9c13683c9).

## Состав

- `upstream.json` — закреплённая ревизия исходного FPC-порта.
- `patches/` — изменения для внешнего исходного порта.
- `assets/` — собственные новые ассеты и сведения об их происхождении.
- `docs/encyclopedia/` — авторский справочник и проверяемые каталоги исходной игры.
- `tools/` — инструменты локального извлечения и проверки каталогов.
- `.gitattributes` — правила хранения бинарных ассетов через Git LFS.

Исходные файлы купленной игры, сохранения, ключи API и приватные исследовательские материалы в репозиторий не входят. Для запуска понадобится собственная установленная игра.

## Git LFS

После клонирования:

```sh
git lfs install --local
git lfs pull
```

Перед отправкой новых ассетов:

```sh
git lfs status
git lfs fsck
```

Git хранит LFS-указатели на бинарные файлы и сжатые крупные индексы энциклопедии. Обычные JSON, Markdown, исходники и текстовые SVG остаются в истории Git. Миграцию уже опубликованной истории нужно проводить отдельно, согласовав её последствия.
