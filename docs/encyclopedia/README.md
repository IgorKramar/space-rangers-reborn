## Правила использования

- Название в локализации, объект сохранения и факт лора — разные сущности. Список имён не является одной неизменной картой галактики.
- Высказывание персонажа сохраняет своего рассказчика. Слух, обман, рекламное описание и виртуальный эпизод не повышаются до всеведущего факта мира.
- Взаимоисключающие финалы представлены как варианты. Один исход не назначается обязательной историей без отдельного решения.
- Сценарий о выборах или колонии подтверждает исходную тему; он не доказывает наличие выборов или производственной экономики на всех планетах.
- Новая Оттепель и её персонажи относятся к проекту «Возрождение». Авторские расширения не добавляются в каталог оригинальной игры.

## Каталоги и права

JSON/CSV содержат имена, идентификаторы, числовые определения, ссылки и метаданные. Полные оригинальные диалоги, квесты, изображения, звук, архивы игры и пользовательские сохранения не публикуются. Установленная игра нужна исследователю для проверки исходного текста по ключу.

Крупные индексы `*.json.gz` хранятся через Git LFS. После `git lfs pull` они читаются стандартным `gzip`/`json`; это индексы путей и хешей, а не упакованные игровые ресурсы. Остальные JSON остаются обычными текстовыми файлами Git.

Все результаты описывают границы выполненного исследования. Декодирование полного контейнера не означает прохождение каждой ветви или доказательство её достижимости в игре.
