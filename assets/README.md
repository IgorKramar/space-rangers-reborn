# Новые ассеты

Здесь хранятся собственные изображения, звук и другие новые ресурсы проекта. Бинарные форматы перечислены в корневом `.gitattributes` и должны добавляться через Git LFS.

Рядом с результатом сохраняются текстовый манифест, назначение, использованные референсы, способ генерации, исходный запрос, модель и версия, параметры, дата и сведения о правах. API-ключи и временные подписанные ссылки не сохраняются.

Основной инструмент генерации — fal-assets. Для больших задников и статичных иллюстраций допускается imagegen. Художественный ориентир — стиль «Космических Рейнджеров»; новые изображения должны сохранять читаемость на Steam Deck.

Оригинальные ассеты из установленной игры сюда не копируются. Первая иллюстрация — [концептуальная обложка «Оттепель»](concepts/ottepel-project-cover-v1.png) для досье в Notion. Рядом сохранены исходный запрос и манифест; изображение пока не интегрировано в игру.
