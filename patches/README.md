# Изменения внешнего порта

Изменения готовятся относительно ревизии из `upstream.json`. В репозитории хранятся собственные новые модули и необходимые патчи; внешние исходники и игровые данные получают отдельно.

Для каждого набора патчей фиксируются исходная ревизия, назначение, порядок применения и фактически выполненные проверки. Автоматического применения и сборки пока нет: эти команды появятся вместе с первым рабочим изменением.
